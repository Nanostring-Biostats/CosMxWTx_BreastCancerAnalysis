8  Low-proliferation zones

Here we characterize regions of low cancer cell profliferation.

8.1 Assign proliferation scores

We start by assigning proliferation scores to each cell, using Seurat’s cell cycle scoring method.

Next, we load in basic data.

Now we lay the groundwork for DE:

Show the code 
if (!file.exists(paste0(prolif_dir, "/Data/overlap_metrics.rds"))) {
  overlap_metrics <-
    smiDE::contamination_ratio_metric(assay_matrix = Matrix::t(raw),
                                      metadata = annot,
                                      cluster_col = "celltype",
                                      radius = 0.05,
                                      sdimx_col = "x_slide_mm",
                                      sdimy_col = "y_slide_mm"
    )
  # Save overlap metrics
  saveRDS(overlap_metrics, file = paste0(prolif_dir, "/Data/overlap_metrics.rds"))
} else {
  overlap_metrics <- readRDS(paste0(prolif_dir, "/Data/overlap_metrics.rds"))
}

## set up DE:
scaling_factors <- Matrix::rowSums(raw)
norm <- Matrix::Diagonal(x = scaling_factors^-1) %*% raw * mean(scaling_factors)

# which genes to keep: low overlap, not low mean
analysis_genes <- overlap_metrics[celltype == "Tumor" & (ratio <= 1)]$target
length(analysis_genes)
norm <- norm[, analysis_genes]

# scale norm:
genefactors <- pmax(Matrix::colMeans(norm), 0.1)
genefactors <- genefactors / mean(genefactors)
norm.s <- norm %*% Matrix::Diagonal(x = 1 / genefactors)
colnames(norm.s) <- colnames(norm)

Now we run DE over each patch:
