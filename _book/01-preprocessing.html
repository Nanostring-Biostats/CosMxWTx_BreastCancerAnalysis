FOVQC

Show the code 
# Object and color setup

  seu.obj <- readRDS(results_list$raw_seurat_file)

## Run FOV QC
if (!file.exists(paste0(qc_dir, "/Data/fovqc.RDS"))) {
   source("https://raw.githubusercontent.com/Nanostring-Biostats/CosMx-Analysis-Scratch-Space/Main/_code/FOV%20QC/FOV%20QC%20utils.R")  
  allbarcodes <- readRDS(url("https://github.com/Nanostring-Biostats/CosMx-Analysis-Scratch-Space/raw/Main/_code/FOV%20QC/barcodes_by_panel.RDS"))
  barcodes <- allbarcodes[["Hs_WTX"]]
  
  smallfovs <- names(which(table(seu.obj@meta.data$fov) < 500))
  tempuse <- !is.element(seu.obj@meta.data$fov, smallfovs)
  
  sharedgenes <- intersect(barcodemap[,1], rownames(seu.obj@assays$RNA@counts))
  res <- runFOVQC(counts = t(seu.obj@assays$RNA@counts)[tempuse, sharedgenes], 
                  xy = seu.obj@meta.data[,c("x_slide_mm", "y_slide_mm")][tempuse, ],

                  barcodemap = barcodemap[match(sharedgenes, barcodemap[, 1]), ],

  str(res)
  saveRDS(res, file = paste0(qc_dir, "/Data/fovqc.RDS"))

1.4 Cell Typing

In this section we assign major and minor cell types using a combination of iterative unsupervised clustering and marker-based hierarchical assignment.

Click to show/hide cell typing steps

This section performs cell typing of the dataset with a multistep approach. First, we use unsupervised clustering to broadly group the cells. For some of these major cell types (tumor cells, fibroblasts, vascular cells) we subset and perform unsupervised clustering a second time on the subset. For immune cells, we use the marker-based hierarchical cell typing approach HieraType.

1.4.2 Refine cell type annotations

These unsupervised clusters do a pretty good job of splitting apart major cell types. We follow this up by naming and refining this initial clustering result based on spatial distribution, top marker genes, and position in UMAP space. In particular, we’ll recluster the tumor cells on their own to reduce the number of clusters and subcluster the fibroblast and vascular clusters. Additionally, we’ll use HieraType to perform targeted marker-based annotation of the immune cells. We start with our evaluation and planned actions for each cluster:

We start with fibroblasts since this cluster is near immune clusters and may be partially overlapping. The initial unsupervised clustering had only one fibroblast cluster, but from previous experience with this sample we expect that we should be able to identify a few subtypes. Additionally, it appears that the cluster that is mostly fibroblast may also contain some immune cells. Here we take the fibroblast cells, repeat initial preprocessing so that highly variable genes are chosen based on these cells, and use unsupervised clustering to separate these cells into multiple clusters, some of which we’ll add to the immune cells for HieraType clustering.
