# CosMxWTx_BreastCancerAnalysis

This repository contains analysis files for the work by Williams et al. (2026), "Breast cancer through the lens of whole transcriptome spatial imaging".

To begin, first download the Seurat object from [our website](https://brukerspatialbiology.com/products/cosmx-spatial-molecular-imager/ffpe-dataset/cosmx-human-multiomic-breast-dataset/) for from [Zenodo](https://zenodo.org/records/18943070).
