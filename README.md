# CosMxWTx_BreastCancerAnalysis

This repository contains analysis files for the work by [Williams et al. (2026), "Breast cancer through the lens of whole transcriptome spatial imaging"](https://www.biorxiv.org/content/10.64898/2025.12.19.695622v1).

To begin, first download the Seurat object from [Zenodo](https://zenodo.org/records/18943070).
